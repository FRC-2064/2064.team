**Who:** all rookie members. **Deadline:** January 1.

This is the path from no CAD experience to a design-subteam contribution. You complete this module by submitting an Onshape document at the end of each stage, not by a quiz. Finish Module 1.2 by January 1 if you want to help build during build season. Veterans can use it as a refresher or go to Phase 2.

:::danger
This module should be done by January 1. That is the expectation for rookies who want to help build. The stages are in order. Do not skip a prerequisite.  If we all can know how to use OnShape we can all know what parts need to be made and what parts go where, even if you are unable to contribute to the CAD model.
:::
