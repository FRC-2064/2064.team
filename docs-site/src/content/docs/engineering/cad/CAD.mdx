> **Target Audience:** All Rookie Members | **Deadline:** January 1st

Welcome to the Team 2064 CAD Foundations. This is a self-paced, project-based module that takes you from no CAD experience to a contributing member of the design subteam.

By completing these stages, you will be able to help design the competition robot in Onshape during Build Season.

:::danger[Hard Deadline]
**All rookie members must complete Module 1.2 by January 1st** to be eligible for the travel team in March. Veteran members can use this as a refresher or go straight to their Phase 2 specializations.
:::

:::note[Course Attribution]
This curriculum is adapted from the [FRCDesign.org Learning Course](https://www.frcdesign.org/). Use that site for deeper dives into FRC modeling strategy.
:::

:::note[Prerequisites]
Each stage starts with a prerequisite outline. Demonstrate mastery of the current stage before moving to the next.
:::

## The method to completion

You pass this course by project-based mastery. There are no multiple-choice tests. You move through four stages of increasing complexity, and at the end of each stage you submit your Onshape document link to the 2064 Onshape Classroom for review.
