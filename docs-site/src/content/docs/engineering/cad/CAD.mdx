**Who:** all rookie members. **Deadline:** January 1.

This is the path from no CAD experience to a design-subteam contribution. You pass by submitting an Onshape document at the end of each stage, not by a quiz. Finish Module 1.2 by January 1 if you want to help build during build season. Veterans can use it as a refresher or go to Phase 2.

:::danger
This module should be done by January 1. That is the expectation for rookies who want to help build. The stages are in order. Do not skip a prerequisite.
:::

## Before Stage 0

FIRST's Module 3 is about two and a half hours on how FRC teams use CAD and 3D printing. FIRST recommends it before kickoff. It is the overview. The stages below are the 2064 credential, in Onshape.

Dashboard login if you want the credit stored. For modeling strategy beyond these stages, use the [FRCDesign.org learning course](https://www.frcdesign.org/).
