## The parts that stay

Mechanisms change every game. These do not.

* **Frame and drivetrain.** The skeleton and the wheels. Tank drive runs each side together. Swerve steers each corner. If this fails, the rest of the robot does not matter.
* **Battery.** One 12-volt sealed lead-acid pack. Anderson SB50 connector. No second pack in a match.
* **Main breaker.** The big red 120 A switch. Robot on and off, and the last over-current stop.
* **PDH.** Splits that power into channels. Each channel has its own breaker or fuse.
* **Motor controller, then motor.** A motor never wires straight to the PDH. The controller takes a command and switches battery power to the motor.
* **roboRIO.** Runs the code and sends those commands. It does not power the drive motors.
* **Radio.** Links the robot to the driver station and the field. No link, no teleop, even if the code is fine.
* **CAN bus.** Yellow and green wires between the roboRIO, the PDH, and the motor controllers. A bad CAN wire can look like a dead motor.
* **Driver station.** Not on the robot. Laptop, FRC Driver Station software, controllers, and an Ethernet cable.
* **Bumpers.** Required contact zone, team number, and frame protection.

Power order, battery terminals to a drive motor: battery, main breaker, PDH, branch breaker, motor controller, motor.
