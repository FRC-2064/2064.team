**Objective:** Name the parts on every Team 2064 robot, and say how power and control get from the battery to a wheel.

:::danger
Finish every section of Module 1.1 before you are in the shop. Then tell a mentor you are ready to start safety training.
:::

Mechanisms change every game. These parts do not.

<CardGrid>
  <Card title="Frame and drivetrain" icon="puzzle">
    The skeleton and the wheels. Tank runs each side together. Swerve steers each corner. If this fails, nothing else matters.
  </Card>
  <Card title="Battery" icon="warning">
    One 12-volt sealed lead-acid pack. Anderson SB50. No second pack in a match.
  </Card>
  <Card title="Main breaker" icon="error">
    The big red 120 A switch. Robot on and off, and the last over-current stop.
  </Card>
  <Card title="PDH" icon="list-format">
    Splits battery power into channels. Each channel has its own breaker or fuse.
  </Card>
  <Card title="Motor controller, then motor" icon="setting">
    A motor never wires straight to the PDH. The controller takes a command and switches battery power to the motor.
  </Card>
  <Card title="RoboRio/SystemCore" icon="laptop">
    Runs the code and sends commands. It does not power the drive motors.
  </Card>
  <Card title="Radio" icon="rss">
    Links the robot to the driver station and the field. No link, no teleop.
  </Card>
  <Card title="CAN bus" icon="random">
    Yellow and green wires between the RoboRio/SystemCore, the PDH, and the controllers. A bad wire can look like a dead motor.
  </Card>
  <Card title="Driver station" icon="monitor">
    Not on the robot. Laptop, FRC Driver Station, controllers, and an Ethernet cable.
  </Card>
  <Card title="Bumpers" icon="approve-check">
    Required contact zone, team number, and frame protection.
  </Card>
</CardGrid>

Power order, battery to a drive motor: battery, main breaker, PDH, branch breaker, motor controller, motor.
