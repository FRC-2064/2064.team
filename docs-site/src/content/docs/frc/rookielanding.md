# 🏁 Phase 1: Rookie Foundations

> **Target Audience:** Mandatory for all new The Panther Project - FRC Team 2064 members.

Welcome to The Panther Project - FRC Team 2064! Before you can build a 125-pound competition robot, you need to master the basics. Phase 1 is your onboarding bootcamp.

In this phase, you will learn the culture of FIRST Robotics, how to safely navigate our machine shop, basic CAD principles, and how to use core hand tools. You will cap it all off by building and programming a miniature XRP Starter Bot.

:::note
**How to Complete Phase 1** Work through these modules at your own pace. You **must** complete and pass the Safety Certification (Module 1.3) before you are allowed to touch any tools for Modules 1.4 and 1.5.
:::

---

## 🗺️ Your Training Modules!

### 🤖 Module 1.1: FRC Basics
**Status:** SELF PACED ~ *Learn the culture.* Get an overview of FIRST, understand robot anatomy, analyze a past game, and learn what to expect during Build Season.

👉 **[Start Intro to FIRST](/frc/FIRST/)**

---

### 💻 Module 1.2: Basic CAD
**Status:** MUST COMPLETE MODULE 1.1 ~ *Learn to think in 3D.* Master the Engineering Design Process and get your Onshape account set up for basic mechanism modeling.

👉 **[Start Stage 0 (New to CAD)](/engineering/cad/CAD/)**

---

### 🛡️ Module 1.3: Safety Certification
**Status:** MUST COMPLETE MODULE 1.1 ~ Learn our core shop rules, machine safety, and pass your written quiz and 1.3.4 - Safety Practical.

👉 **[Start General Safety](/safety/safetylanding/)**

---

### 🛠️ Module 1.4: Basic Fabrication
**Status:** MUST COMPLETE MODULE 1.3 ~ *Get hands-on.* Learn how to organize the workspace, use hand tools, identify fasteners, and safely crimp/solder electronics.

👉 **[Start Workspace Organization](/fabrication/fabricationbasic/)**

---

### 🏎️ Module 1.5: XRP Starter Bot
**Status:** MUST COMPLETE MODULE 1.2/STAGE 1A & MODULE 1.3 ~ *Put it all together.* Assemble, wire, and program a functional mini-robot using WPILib and Java to prove your baseline engineering skills.

👉 **[Start Build Guide](/xrprobotics/xrplanding/)**
