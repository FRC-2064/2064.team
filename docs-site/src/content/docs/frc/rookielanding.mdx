**Mandatory** for incoming members of the Panther Project, FRC Team 2064.

Phase 1 is the shared floor: what *FIRST* is, how a robot is put together, shop clearance, basic CAD, an XRP robot, and hand tools. You do not need to finish CAD before you start safety. You do need safety clearance before you use a shop tool. The XRP is not a shop tool.

:::danger
Start safety while you are in 1.1 and 1.2. Do not wait until CAD is done. Module 1.3 has to be passed before fabrication tools and before 1.4. It is not required for the XRP.
:::
