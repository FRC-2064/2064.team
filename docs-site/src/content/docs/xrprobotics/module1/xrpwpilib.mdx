## Installing WPILib and VS Code onto your Personal Computer

:::note
**WPILib Installation**
Your workstation must have macOS or Windows installed. Reference the linked page below for specific architecture required based on your operating system. Linux could work, but may have issues to troubleshoot with simulation. **Chromebooks will not work for this**. The computers in Room 124 already have VS Code with the WPILib libraries installed, so you are free to use them and can skip this step - but if you would like to use a personal computer or update WPILib, this step will help you with that.
:::
